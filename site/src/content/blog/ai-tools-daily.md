Everyone has a list of fifty AI tools. We do not. We have a short list we open every day, and a rule: if a tool does not earn its place weekly, it gets cut.

Here is the current list, and what each one is actually for.

## Writing and thinking

A conversational AI for drafts, outlines, and working through ideas. We use it the way you would use a sharp colleague: give it context, argue with the output, keep what survives.

The skill is not prompting. It is knowing what good looks like, so you can tell when the output is not.

## Building

AI coding assistance for the builders shipping software. It writes the boring parts fast — boilerplate, tests, glue code — and the builder reviews everything. Nothing ships without a human reading it.

## Research

AI search for the first pass on any unfamiliar topic: competitors, pricing, regulations. It is a starting point, never a source. Anything that matters gets verified against the original.

## The rule behind the list

Tools change every quarter. The list will look different in six months, and that is fine. What does not change: small stack, used daily, every tool earning its place.

Start with one. Use it until you are fluent. Then add the next.
